ABOUT ECOSORT

Interpretable algorithms, connected end to end

This academic implementation keeps model provenance visible and distinguishes synthetic demonstrations from real dataset evaluation.

01

MobileNetV2

Transfer-learning pipeline uses a pretrained backbone with a six-class head. An ImageNet model alone is not presented as a waste classifier. Fine-tuning requires labeled, licensed examples.

02

Sugeno ANFIS

Four numeric inputs are fuzzified into Gaussian LOW, MEDIUM, HIGH sets. A compact selected rule base normalizes firing strengths and weights consequent functions.

03

Genetic programming

GP evolves executable boolean expression trees. Crossover exchanges subtrees; mutation replaces a subtree with a newly generated one. Complexity is penalized.

04

Genetic algorithm

GA evolves real-valued center and width parameters with bounds and ordered centers. Inversion and deletion are optional structure-preserving changes.

Current limitations

  • No waste-labeled image set or fine-tuned checkpoint is bundled.
  • Fuzzy and evolutionary demonstration targets are transparent heuristics, not verified recycling outcomes.
  • Material acceptance varies by location; follow local recycling and hazardous-waste guidance.
  • Training, validation, and testing metrics are only meaningful after supplying a documented labeled dataset and target definitions.
